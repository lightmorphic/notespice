Cookies

What this website stores on your device.

This site sets no cookies

There are none. Not ours, not anybody else's, not for analytics, not for preferences, not "essential" ones either. There is no cookie banner because there is nothing to ask you about.

Nothing else is stored either

The site does not use local storage, session storage or any other way of keeping data in your browser between visits. The editor on the home page keeps what you type in memory only, and loses it the moment you close the tab.

Nothing is loaded from anywhere else

Every file the site needs, including the typeface and the images, is served from this domain. No fonts, scripts or images are fetched from another company, so no third party is in a position to set anything on your device through this site.

If that ever changes

It would be written here first, and this page would say what is set and why. If you want to check for yourself, your browser's developer tools will show an empty cookie list for this domain.
